## 📌 About The Project

**Unsplash Image Search** is a frontend web application that allows users to search for images using the Unsplash API.

The application provides a simple and clean search interface where users can enter a keyword and instantly get relevant images.

If no images are found, the application displays a user-friendly **"No Results Found"** message.

---

## ✨ Features

- 🔍 Search images by keyword
- 🖼️ Display high-quality images from Unsplash
- 📱 Fully responsive design
- 💻 Desktop, tablet and mobile support
- ⚡ Fast API-based image search
- 🎨 Modern and clean user interface
- 🖱️ Image hover effects
- 🚫 No-results message
- 🔄 Dynamic image rendering using React
- 🌐 Unsplash API integration
